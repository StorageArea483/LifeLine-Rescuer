# LifeLine - Rescuer Mobile Application

## About

LifeLine is a disaster relief and emergency response system designed to
improve communication and coordination between victims, rescuers, NGOs,
and administrators during emergencies such as earthquakes, floods,
landslides, accidents, and other critical situations.

This repository contains the **Rescuer Mobile Application**, which helps
rescuers receive emergency requests, view victim locations, communicate
with victims, and coordinate rescue activities.

## Key Features

-   Secure rescuer authentication and account access.
-   Receive and manage emergency/SOS requests.
-   View victim locations on an interactive map.
-   Track emergency locations using GPS.
-   Communicate with victims through real-time messaging.
-   Support voice and video communication.
-   Receive and manage emergency-related information.
-   Support connectivity changes during emergency situations.

## Installation

``` bash
git clone https://github.com/StorageArea483/LifeLine-Rescuer.git
cd LifeLine-Rescuer
flutter pub get
flutter run
```

Make sure Flutter, Dart, Android Studio/Xcode, and the required Firebase
configuration are properly set up before running the application.
