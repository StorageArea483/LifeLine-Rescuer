# LifeLine - Rescuer Mobile Application

## 🚨 About LifeLine

LifeLine is a disaster relief and emergency response system designed to
improve communication and coordination between **victims, rescuers,
NGOs, and administrators** during emergencies such as earthquakes,
floods, landslides, accidents, and other critical situations.

This repository contains the **Rescuer Mobile Application**, which is
the rescuer-facing component of the complete LifeLine system.

The rescuer application allows authorized rescuers to:

-   Authenticate and access the rescuer platform.
-   Maintain their profile information.
-   Receive emergency/SOS requests from victims.
-   View victim and emergency locations on an interactive map.
-   Access location information during rescue operations.
-   Communicate with victims and other relevant users.
-   Use real-time voice/video communication.
-   Receive and manage emergency-related information.
-   Continue working with the application during changing network
    conditions.

The overall LifeLine system integrates the rescuer application with
separate victim, NGO, and administrator applications.

------------------------------------------------------------------------

## 🎯 Objectives

The main objectives of the rescuer application are:

1.  **Improve emergency response coordination** between victims and
    rescuers.
2.  **Provide rescuers with accurate victim location information**.
3.  **Help rescuers receive and respond to SOS emergency requests**.
4.  **Support communication** between rescuers and victims during
    emergencies.
5.  **Provide map-based awareness** for rescue operations.
6.  **Support voice and video communication** when required.
7.  **Provide reliable access to emergency information** during unstable
    connectivity.
8.  **Improve the overall response time** during disaster and emergency
    situations.

# 🚀 Installation & Setup

## 1. Clone the Repository

``` bash
git clone https://github.com/StorageArea483/LifeLine-Rescuer.git
```

``` bash
cd LifeLine-Rescuer
```

## 2. Install Dependencies

``` bash
flutter pub get
```

## 3. Configure Firebase

Make sure the Firebase configuration used by the local build corresponds
to the intended LifeLine project.

The application uses Firebase services for authentication and cloud data
functionality.

## 4. Configure Required Services

Configure any required backend or service credentials according to the
application's source-code configuration.

**Do not commit private API keys, passwords, tokens, or service
credentials to GitHub.**

## 5. Check Connected Devices

``` bash
flutter devices
```

## 6. Run the Application

``` bash
flutter run
```

For a specific device:

``` bash
flutter run -d <device-id>
```
